Solution Strategy & Why it Works
- We built the lock manually using a global semaphore (monitor_mutex) set to 1 
  with RTTPRIORITY.
- RttMonEnter does RttP, RttMonLeave does RttV.
- For condition variables, we used an array of lists from our A1 library.
- When a thread waits, it makes its own private semaphore (set to 0), puts it
  in the CV list, drops the main lock, and sleeps on its private semaphore. 
- When signaled, we pop the first semaphore off the list and wake it up. 
- Why it works: Dropping the main lock before sleeping prevents deadlocks. 
  Grabbing it again right after waking up keeps the monitor safe.

 Code Changes & Removals
- Changed <os.h> and <standards.h> to <rtthreads.h> from reader_writer.c.
- Replaced PID, Create(), and Sleep() with RttThreadId, RttCreate(), and 
  RttSleep() to actually use the RT Threads API.
- Removed -lpthreads from the reader/writer Makefile target. 
Linking it alongside
  -lRtt caused multiple definition errors for 'main'.
- Added -lRttUtils to the Makefile so it could find RttSleep.

 What We Learned from Discussions & API Docs
- canvas: Prof Makaroff confirmed we need to add the Rtt prefix to all 
  monitor functions (like RttMonWait). 
- canvas: The provided test file didn't actually initialize the monitor. We 
  had to add Initialize() inside mainp() to fix this.
- API Docs: RttCreate requires an RttSchAttr struct for scheduling. 
- API Docs: RttAllocSem needs a mode flag, so we picked RTTPRIORITY.


 Pseudocode

RttMonInit(numConds):
    RttAllocSem(&monitor_mutex, 1, RTTPRIORITY)
    for i = 0 to numConds - 1:
        cv_lists[i] = ListCreate()

RttMonEnter():
    RttP(monitor_mutex)

RttMonLeave():
    RttV(monitor_mutex)

RttMonWait(cv):
    private_sem = allocate new semaphore(0, RTTPRIORITY)
    ListAppend(cv_lists[cv], private_sem)
    
    RttMonLeave()       /* drop main lock */
    RttP(private_sem)   /* go to sleep */
    free(private_sem)
    
    RttMonEnter()       /* grab lock again after waking up */

RttMonSignal(cv):
    if ListCount(cv_lists[cv]) > 0:
        ListFirst(cv_lists[cv])
        popped_sem = ListRemove(cv_lists[cv])
        RttV(popped_sem) /* wake the specific thread */
